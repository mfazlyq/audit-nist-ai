## About

I am a computer science professional interested in building practical technology through applied artificial intelligence, research, and software engineering.

My interests sit at the intersection of **AI research, computer vision, medical image analysis, information systems, and cybersecurity governance**. I value reproducible experiments, clear documentation, and solutions that connect technical methods with real-world needs.

- 🎓 **Academic background:** Informatics Engineering and Master of Computer Science, Universitas Esa Unggul.
- 🧠 **Research interests:** Deep learning, computer vision, 3D medical image segmentation, and attention-based neural networks.
- 🛡️ **Applied technology:** AI-assisted cybersecurity assessment and NIST CSF 2.0.
- 🧩 **Engineering interests:** Python applications, data workflows, information systems, and research prototypes.

## Featured project

### 🛡️ NIST AI Audit Assistant

A Streamlit research prototype that explores AI-assisted review of campus cybersecurity policies and procedures against the NIST Cybersecurity Framework (CSF).

**Technologies:** Python · Streamlit · LangChain · Chroma · Hugging Face Embeddings · Groq

[View repository →](https://github.com/mfazlyq/audit-nist-ai)

> The application is a decision-support prototype. AI-generated findings require source verification and review by a qualified auditor.
